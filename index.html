      How the scores work (and why you should argue with them)
      

        
Learning value adds up how well each device fits the space's goal (0 to 3, shown on each device), with diminishing returns: the tenth sensor adds less than the second. Devices that personalize instruction lose most of their value if you make their data anonymous, and opt-in consent trims value slightly because fewer people take part.

        
Intrusiveness starts from how sensitive the data is (room air is low; faces and brainwaves are high), then scales by your four data rules. Tying data to names, making it mandatory, keeping it forever, and letting the institution see it all push the score up.

        
These weights are one instructor's judgment, set on purpose to be debatable. If you think a device is scored wrong, say so in your discussion post and make the case.
